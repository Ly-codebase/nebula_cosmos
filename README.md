Nebula Cosmos · 星云知识宇宙 v3.8
====================================

一个基于 D3.js 构建的交互式知识图谱可视化工具，用于管理书籍阅读记录，并以"星云宇宙"的形式展示知识之间的关系。支持书籍、作者、国家、主题、标签等多维度节点，并具备搜索、筛选、笔记编辑、数据导入导出等功能。


✨ 功能特性
------------

- 知识录入：添加书籍信息，包括书名、作者、国家、主题、标签、完读月份和笔记。
- 图谱可视化：以力导向图形式展示知识节点，节点类型包括书籍、作者、国家、主题、标签。
- 交互操作：
  - 拖拽节点调整布局
  - 点击节点查看详细信息
  - 滚轮缩放、拖拽移动画布
- 搜索与筛选：
  - 按节点名称搜索并高亮关联节点
  - 按完读月份筛选显示
- 笔记编辑：在详情面板中直接编辑并保存书籍笔记。
- 数据管理：
  - 导出为 CSV 文件
  - 导入 CSV 文件恢复数据
  - 一键清空所有数据
- 数据持久化：所有数据保存在浏览器的 localStorage 中，刷新页面不丢失。


🛠️ 技术栈
----------

- D3.js v7 — 数据可视化与力导向图布局
- HTML5 + CSS3 — 界面结构与样式
- JavaScript (ES6) — 交互逻辑与数据管理
- localStorage — 本地数据持久化

🚀 快速开始
-----------

1. 下载或克隆本项目
   git clone https://github.com/your-username/nebula-cosmos.git
   cd nebula-cosmos

2. 直接在浏览器中打开 index.html
   - 无需安装任何依赖或启动服务器。
   - 所有数据存储在浏览器本地。


📖 使用指南
-----------

录入新知识：
- 填写表单中的书名、作者、国家、主题（用 / 分隔）、标签（用 / 分隔）、完读月份和笔记。
- 点击"添加到知识宇宙"即可生成新的节点和关系。

图谱交互：
- 拖拽节点：调整布局位置。
- 点击节点：右侧弹出详情面板，可查看或编辑笔记。
- 滚轮缩放：缩放视图。
- 拖拽背景：平移画布。

搜索与筛选：
- 输入关键词搜索，匹配的节点及其关联节点会高亮显示。
- 可通过"完读月份"下拉菜单筛选特定月份的书籍。

数据导入 / 导出：
- 点击"导出 CSV"下载当前所有数据。
- 点击"导入 CSV"上传之前导出的文件，恢复数据。

清空数据：
- 点击"清空宇宙数据"将删除所有本地存储数据（需确认）。

📝 数据格式说明（CSV）
---------------------

导出的 CSV 文件包含以下列（UTF-8 编码，带 BOM）：

列名        说明
书名        书籍标题
作者        作者姓名
国家        作者所属国家
完读月份    格式为 YYYY-MM
主题        多个主题用 / 分隔
关键词      多个标签用 / 分隔
笔记        自由文本内容


🧩 自定义与扩展
---------------

- 修改配色：可调整 CSS 中的渐变与颜色变量。
- 调整节点大小：在 render() 函数中修改 circle 的 r 属性值。
- 增加新节点类型：在 store.getNodes() 和 store.getLinks() 中添加逻辑。
- 连接外部后端：可将 localStorage 替换为 API 调用。


⚠️ 注意事项
-----------

- 本工具完全运行在浏览器端，所有数据仅保存在本地，清除浏览器缓存会导致数据丢失。
- 建议定期导出 CSV 备份数据。
- 推荐使用最新版 Chrome / Edge / Firefox 浏览器以获得最佳体验。
